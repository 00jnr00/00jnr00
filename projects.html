F150 Variable-Rate Rocker-Linked Damper System

Suspension Design Additive Manufacturing Vehicle Dynamics PA12 CF
In Development — Rev 1 Rocker Printed · Triple-Rate Variant Planned

Ground-up suspension architecture for a 2005 Ford F-150 triple-duty build — pre-runner, street, and bog. The system uses a rocker-linked tandem damper arrangement with one stiff and one soft adjustable shock to produce variable effective spring rate across travel. Geometry: 1:1 arm ratio, 6" pivot-to-pivot, 90° at static ride height. Leaf springs retained for load carrying and axle location only — fully decoupled from damping function.

Rev 1 rocker arm printed in PA12 CF with bronze bushings heat-pressed after sand annealing. Five-day validation protocol defined: static load, dynamic articulation, thermal cycling, on-vehicle behavior. Currently evaluating a triple-rate variant for higher-capacity damping across a wider travel range. Long-term roadmap: F150 → bolt-on kit → full custom frame → production vehicle.

Fluid Systems Additive Manufacturing Thermodynamics PPA-CF
Field Validated — 4+ Weeks Engine Bay Heat Soak

Water/methanol injection nozzle that eliminates the PWM pump entirely through venturi-based vacuum ejection geometry. Regulated compressed air at 25–75 PSI creates near-sonic choked flow at a precision orifice, drawing and atomizing fluid without a pump, a controller, or complex wiring. Ray-Cast Surrogate CFD Estimator

CFD Numerical Methods Python Geometry Processing
Active — In-House Design Tool

Surrogate CFD estimator using ray-casting to approximate flow area and blockage characteristics in complex geometries. Runs fast enough to screen variants during active design iteration — not after. Pre-CFD filter before committing to full-resolution simulation.

mesh subdivision via ray-casting
def slice_grid(mesh, x, N):
    ymin, zmin = mesh.bounds[0][1:]
    ymax, zmax = mesh.bounds[1][1:]
    ys = np.linspace(ymin, ymax, N)
    zs = np.linspace(zmin, zmax, N)
    x0 = mesh.bounds[0][0] - 0.5
    origins = np.array([[x0, y, z] for y in ys for z in zs])
    dirs = np.tile([1, 0, 0], (len(origins), 1))
    hits = mesh.ray.intersects_any(origins, dirs)
    return hits.reshape(N, N).astype(float)
