ENGINEERING — 3.6L INLINE-4 ROTARY VALVE ENGINE

CAD • Simulation • Internal Combustion Engines

Over the course of two months, I designed and simulated a 3.6L inline-4 internal combustion engine using Fusion 360, Blender, and an open-source ICE simulation tool.

This design replaces traditional camshafts and poppet valves with a rotary valve system, combining valve actuation and timing into a single rotating assembly. Using mechanical seals and carbon bushings, the design enables significantly increased airflow and mechanical simplicity. Simulations indicate approximately 900 horsepower at the crank (~250 hp/L), exceeding current naturally aspirated specific output benchmarks.

In Blender, I created textured, photorealistic renders of major components and assemblies. A full technical summary, renders, and simulation data are available below.

PROGRAMMING — OBSIDIANDART (CLI ENCRYPTION TOOL)

C++ • Cryptography • Linux • Security

ObsidianDart is a lightweight, command-line encryption utility written in C++ for Linux systems. It is designed for simple, local encryption workflows rather than full-scale password management.

The tool relies on system-provided cryptographic libraries (OpenSSL) to perform AES-256 encryption and allows users to encrypt or decrypt files stored in the local working directory. Data may be formatted using tab- or comma-separated values for compatibility with external tools.

ObsidianDart is intentionally minimal in scope, focusing on local file encryption with a small codebase and no cloud dependencies. Source code is currently being cleaned, documented, and prepared for public release.

COMPUTATIONAL ENGINEERING — RAY-CAST SURROGATE CFD ESTIMATOR

CFD • Numerical Methods • Geometry Processing • Performance Estimation

This project implements a surrogate computational fluid dynamics (CFD) estimator using ray-casting techniques to rapidly approximate flow behavior and pressure characteristics in complex geometries.

The system is designed to provide hyper-accelerated performance estimation compared to traditional CFD solvers, enabling rapid iteration during early-stage design and optimization. Heres a small codeblock that illustrates the model subdicision with raycsting. 


def slice_grid(mesh, x, N):
    ymin, zmin = mesh.bounds[0][1:]
    ymax, zmax = mesh.bounds[1][1:]

    ys = np.linspace(ymin, ymax, N)
    zs = np.linspace(zmin, zmax, N)

    x0 = mesh.bounds[0][0] - 0.5
    origins = np.array([[x0, y, z] for y in ys for z in zs])
    dirs = np.tile([1, 0, 0], (len(origins), 1))

    hits = mesh.ray.intersects_any(origins, dirs)
    return hits.reshape(N, N).astype(float)

The estimator serves as a pre-CFD screening tool to identify promising geometries before committing to full-resolution simulations.

ENGINE SIMULATION — BMEP & PERFORMANCE MODELING

Engine Modeling • Thermodynamics • Performance Simulation

This project focuses on brake mean effective pressure (BMEP)-based engine simulation to estimate torque, power, and volumetric efficiency across operating ranges.

The model is used to compare engine architectures, airflow configurations, and combustion assumptions to guide early-stage engine design decisions.

The simulation framework allows rapid exploration of displacement, RPM range, and airflow assumptions to assess feasibility prior to detailed mechanical design.
